# Kwentify

**Personal Finance Tracker**

Kwentify is a personal finance tracking web application designed to help users monitor their financial activities, manage their money, and understand their overall financial position.

The application uses a React-based frontend and an Express.js backend, with Firebase for authentication and administrative services.

## Features

Kwentify aims to provide a centralized interface for personal financial management.

- **Dashboard:** View a summary of financial information.
- **Transaction Tracking:** Record and review financial transactions.
- **Budget Management:** Organize spending and monitor budget limits.
- **Savings Tracking:** Monitor savings progress and financial goals.
- **Investment Tracking:** Track investment holdings and performance.
- **Account Management:** Organize financial accounts and balances.
- **User Authentication:** Support account registration, login, and password recovery.
- **User Settings:** Manage profile details, appearance, regional preferences, notifications, security, and data management.
- **Theme Preferences:** Choose light, dark, or system-based appearance.
- **Responsive Interface:** Support different screen sizes.

_Feature availability depends on the current implementation._

## Security

Kwentify uses security-related packages and Firebase services to support safer application development.

- **Helmet:** Configure appropriate HTTP security headers.
- **CORS:** Restrict cross-origin requests to trusted frontend origins.
- **Rate Limiting:** Limit repeated requests to selected API endpoints.
- **Firebase Authentication:** Manage user authentication.
- **Firebase Admin SDK:** Perform privileged Firebase operations on the backend.
- **Environment Variables:** Separate configuration and private credentials from source code.
